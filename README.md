# travel_app_media

Public media for the wander. audio-guide app: guide photos and narration audio only.

- `images/heroes/`, `images/thumbs/`, `images/stops/`: photos from Wikimedia Commons under free licences (CC0, public domain, CC BY, CC BY-SA). The author and licence for every file are listed in `manifest.json`.
- `audio/<lang>/<guide>-<stop>.mp3`: narration. These are test recordings made with free Piper voices.
- `manifest.json`: maps image and audio keys to jsDelivr URLs pinned to a commit.
